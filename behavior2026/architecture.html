0 · Training pipeline — produces the weights for stages 3–4 SFT validated · engine gated Sepoffline, H100 + sim fleet

Never present in the Docker. Output = one checkpoint (policy + heads) and one pointer model. Privileged sim access is legal here and used aggressively.

  1. Sources: 20k teleop demos (200/task; RGB video + proprio(T,61) + action(T,23)) + raw sim-state HDF5s (state(T,623) per episode) + our own rollouts (later rounds).
  2. Label factory (validated ✓): official playback restores each recorded state into live sim → registry reads → pose_obj(T,7) per object → POINT3D labels (project into each camera for pointer supervision; keep 3D for the policy's point token), STAGE labels (BDDL predicate flips, in q-units), EE poses, failure labels for metacog.
  3. Pointer training (separate small model): frozen DINOv2-class features + heatmap head; loss = cross-entropy on label pixel; benchmark = held-out frames, % within object mask + 3D error. Gate Aug 4.
  4. Policy SFT = flow-matching regression on demo chunks. Losses: FM loss (correlated noise from action-covariance Cholesky; 15 samples/step) + FAST aux ×0.05 + stage-CE aux + point-noise augmentation (train points jittered to match the pointer's measured error, so eval-time estimates don't surprise the policy). LoRA variant for cheap validation runs; full fine-tune for the G4 base (~90 tasks, ~1150 H100-h).
  5. RFT round-0: collect rollouts with the base → keep successes → re-train with AWR weights (advantage = predicate delta, applied as loader sampling weights). No new infrastructure.
  6. Corrective rounds (the distillation): harvest failure states from fleet rollouts → mid-episode restore (validated ✓) → scripted privileged teachers execute recovery in physics (retreat-reapproach, brace, regrasp) → episodes in demo schema → DAgger + AWR retrain vs matched-budget success-replay control arm. Teacher gate Sep 1; kill-check vs control Sep 15.
  7. Metacog calibration: P(fail|stage) head fit on fleet rollouts (sim truth gives labels), conformal threshold set for a target false-alarm rate on held-out rollouts. Never calibrated on leaderboard instances.

1 · Observations validatedevery tick · 30 Hz

The complete test-time interface. Nothing privileged: no object poses, no contacts, no sim internals.

  1. RGB head 720×720×3 + left/right wrist 480×480×3.
  2. DEPTH aligned per-pixel range images, same three cameras. Consumed only by stage 3e.
  3. PROPRIO 61-D: base velocity 3 · trunk 4+4 · arm q/q̇ 7+7 ×2 · grippers 2+2 ×2 · EE poses 7×2.
  4. GOAL the task's BDDL definition (legal at eval): goal literal sets, one or more goal options; e.g. ontop(wood_log, fireplace_rack).
  5. Camera intrinsics K + extrinsics/FK chain (base→torso→head/wrist mounts) — needed to move between pixels and the robot frame.

2 · Task director — symbolic planner designed · W2event-driven · ~1 Hz checks

Pure Python over the goal spec; no learning, no GPU. Decides WHAT to pursue now; never outputs motor commands.

  1. Parse GOAL → ground literals; drop init-true literals (denominator-only); enumerate goal options → pick cheapest option (fewest unsatisfied literals).
  2. Literal lifecycle: each literal is pending → active → satisfied → protected. One literal is active at a time; satisfied literals become protected — the director will veto plans that risk un-satisfying them (metric scores FINAL state only).
  3. Name the targets: active literal ontop(A,B) → emit NAMES = (A = thing to grasp, B = destination) → stage 3.
  4. Progress check (~1 Hz): compare POINT3D history vs expectation — object not moving while policy "carries" it → retry signal (re-approach); N failed retries → skip literal, advance.
  5. Stage estimate: own literal index fused with the policy's STAGE head by majority vote over last k predictions (non-Markovian smoothing).
  6. Endgame: at T−60s emit PARK → stage 5 (retreat arms, freeze base, protect everything satisfied).

3 · Grounding head — name → metric 3D point designed · benchmark gate Aug 4every replan ≈ 0.9 s · frozen during grasp

The only honest source of "where." A small learned detector plus one geometric read of depth. Visually debuggable at every step.

  1. Camera choice: try head camera first; if target confidence low (occluded/out of view), try wrists; if all low → report lost → director may rotate base/torso (search microbehavior).
  2. Features: chosen RGB resized ~256² → frozen DINOv2-class encoder → dense features (h×w×d). (Candidate: reuse policy SigLIP features — decided by the Aug 4 benchmark.)
  3. Coarse heatmap: light head cross-attends NAMES (text embedding) over features → heatmap(h×w) for A and for B.
  4. Refine: crop full-res image around coarse peak (~256² crop of the 720² frame — this is where high resolution lives) → second pass → refined peak (u,v) + confidence.
  5. Unproject (only depth use in the system): z = DEPTH[v,u] → p_cam = z·K⁻¹·[u,v,1] → p_base = T_base←cam(FK) · p_cam.
  6. Stabilize: EMA over recent estimates; confidence gate; freeze while gripper closes (target must not jitter mid-grasp); force refresh on stage change.

4 · Policy — π0.5 core + our conditioning recipe ✓ · conditioning @ G3 Jul 31one chunk ≈ every 0.9 s

3B VLM trunk + 300M flow-matching action expert. Our diffs: what enters the prefix (point + stage tokens, no task-ID) and two aux heads. Identity=language · location=point · progress=stage.

  1. Prefix assembly (computed once per replan, then KV-cached): 3 cams RGB resized 224² → SigLIP → 3×256 visual tokens · GOAL text → ~10–30 language tokens · POINT3D → Fourier features (sin/cos at multiple frequencies per coord, ≈2×~100-d) → linear → 2 point tokens (+stage-role flag) · STAGE → sinusoidal + learned embed → 1 stage token. Total ≈ 800 prefix tokens.
  2. Trunk forward: 18-layer Gemma-2B trunk over the prefix → per-layer KV cache (18, ~800, d) — the context everything below reads. (Our probes read exactly this cache.)
  3. Denoising loop ×10: suffix = PROPRIO 61→proj + noised action chunk a_t(32×32-pad) + FM timestep (sinusoidal). The 300M expert attends into the trunk cache with per-layer learned KV-mixing weights (each expert layer sees a learned blend of ALL 18 trunk layers) → velocity estimate → Euler step. Correlated noise at init.
  4. Aux heads (read the trunk cache): stage logits (→ director vote, 2e) · conformal P(fail|stage) (+ Jacobian-norm brittleness feature) → stage 5.
  5. Output: denoised chunk, sliced to real dims → CHUNK 32 steps × 23-D (base-vel 0:3 · torso 3:7 · armL 7:14 · gripL 14 · armR 15:22 · gripR 22).

5 · Serving layer — chunks → one safe command governor built · A/B running30 Hz

Deterministic post-processing between model and motors. Priority: PARK > recovery > governor > raw chunk.

chunk k |──────── execute 26 of 32 ────────|••4 overlap••| chunk k+1 (replan fires here)|──── execute 26 ────| soft inpainting: first 70% of denoise steps for the 4 overlap actions are inpainted from chunk k → seamless handoff, no jerk
  1. Receding horizon: execute ~26 of 32 actions @30 Hz, replan with 4-action overlap (≈0.87 s cycle — hides the ~0.5–0.7 s inference latency).
  2. Recovery dispatch: if P(FAIL) > conformal threshold → override chunk with the matching trained recovery (brace / retreat-reapproach / regrasp), then resume. Trained in stage 0f; triggered here.
  3. Governor (always-on rate limiter): a_t ← clip(a_t, a_{t−1}±cap) per group — base ±0.06 · torso ±0.02 · arms ±0.08 · grippers free. Suppresses fall-inducing accelerations model-independently.
  4. PARK (from director, T−60s): retreat arms to tuck, zero base velocity, hold — protects satisfied literals to the final-state read. Also the default policy for untrained tasks.

6 · OmniGibson evaluator (the referee) loop validated15k steps ≈ 20 min/episode

Steps physics, renders stage-1 observations (loop closes), and at the FINAL state computes q = satisfied/total literals of the best goal option (success ⇒ q=1). It reads sim state to score; we never do.

Cross-cutting: diagnostics spine

Instruments (per rollout)

  • Step traces — every signal above logged per tick → parquet.
  • Saliency HUD — ∂ACTION/∂RGB overlays + pointer heatmaps + stage/P(FAIL) strips burned into debug video.
  • Failure taxonomy — auto-label rollout end-state: fall / grasp-miss / wrong-object / timeout / achieved-then-lost → dashboard.

Experiments (per gate)

  • Swap test (G3): exchange POINT3D between two contexts → behavior must follow the point (causal proof the token is load-bearing).
  • Probes: ridge decoders on the trunk KV cache — does geometry live where the expert can use it? Tracked across checkpoints and arms.
  • Honest-vs-oracle: identical eval, pointer vs sim-pose points → the gap IS a headline number.
